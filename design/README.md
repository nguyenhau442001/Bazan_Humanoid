# Synapse Humanoid — Industrial Design & Concept Domain

This directory contains aesthetic concepts, 3D blender modeling assets, materials, and product visualization renders.

## Directory Structure

- **`blender/`**: Blender sources (`mico.blend`), shaders, mass evaluation scripts, and high-fidelity render assets.
- **`sketch_shell_a/`**: 2D/3D design canvas concepts, shell variations (Mico, Pico, Luno, Kiko), and aesthetic drawings.
- **`renders/`**: Rendered hero images, multi-angle views, and showcase visuals.
